# Report a sensitive problem

Omit credentials, private code and exploitable account details from public issues. Use [GitHub private vulnerability reporting](https://github.com/MehdiZare/VibeStartKit/security/advisories/new) when it is available. If it is unavailable, open a minimal issue asking the maintainer for a private reporting route, without sensitive or exploitable details.

The setup engine creates a new project from a reviewed plan, can install selected tools and can prepare project-local client/MCP configuration. Report a reproducible bypass of destination isolation, plan validation, file preservation or installation scope.

The generated hook setup is scoped to the new repository. Account authorization, model calls, migrations, cloud creation and deployment are separate actions; generated configuration does not establish a secure or working integration.

Test only against projects and accounts you control. Keep secrets in the provider/client's supported storage or the application's local environment rather than in specifications, prompts or logs.
