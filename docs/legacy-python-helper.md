# Optional Python workflow exercise

The Node CLI is the main application scaffolder. The earlier Python helper remains available for the free offline issue-to-review exercise.

Use Python 3.12+ from the kit checkout:

```sh
python3 starter.py demo --destination ../vibestartkit-demo
python3 starter.py demo --destination ../vibestartkit-demo --apply
python3 starter.py demo --verify
```

The copied baseline intentionally fails its duplicate-delivery tests. Read its ISSUE.md and try the scoped fix before reading the separate reference solution.

This exercise requires no account, API key, model call or cloud service. It teaches acceptance, implementation and handoff with a deliberately small in-memory example; it does not establish production durability or exactly-once processing.

The Python helper's init command can still copy the original two workflow skills/templates. Use the Node CLI for the new monorepo presets, project-setup skill, hook installation and client/MCP configuration.
